# openrouter-model-picker v1.0.0 — First product release

## What changed

- Portable static website download plus local container hosting.
- Audited model filters and prompt/judge handling.
- All assets and local ES modules ship together with release checksums.

## Install and upgrade

Catalog requests and model judging require network access. API keys are supplied in the browser at runtime, never in a build. Open the app over HTTP, not a file URL.

See [deployment instructions](https://github.com/csnyder256/openrouter-model-picker/blob/v1.0.0/DEPLOYMENT.md) and the attached checksums.
