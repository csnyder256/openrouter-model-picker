# Saved and shareable model comparisons — v1.1.0

Save, rename and delete browser-local shortlists; export comparison snapshots as JSON or CSV; and share a bounded comparison in a URL fragment that opens without an API key. Recommendation explanations use the same quality, cost and balanced ranking as the actual picker and describe missing measurements and price assumptions.

Shares include selected public model metadata and benchmark results only. API keys, prompts, tasks, judge results and private shortlist names are excluded. Illustrative comparisons are labeled. Imports validate before changing the current comparison; failed imports preserve it. Refresh preserves the original snapshot when a selected model cannot be refreshed.

## Install and upgrade

Use the versioned [deployment instructions](https://github.com/csnyder256/openrouter-model-picker/blob/v1.1.0/DEPLOYMENT.md) and verify the release checksums before upgrading. Preserve existing user data and policy configuration.

## Verification

80 tests; keyless share in a fresh browser, saved list lifecycle, exports and malformed import preservation. Release CI validates version metadata and packages the published source.
