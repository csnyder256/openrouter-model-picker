Compare up to six models, inspect the ranking formula, and share a public snapshot. Links and exports exclude your API key, task description and judge response. Saved names stay in this browser.

No backend. Every request goes from this page directly to openrouter.ai. Model list and pricing from /api/v1/models; benchmark scores (Artificial Analysis intelligence/coding/agentic indices, and OpenRouter’s own GPQA-Diamond, tau-bench-airline, and web-search evals) from /api/v1/benchmarks. The judging call targets a model whose token price is $0, so getting the recommendation costs nothing. Note that a $0 token price is not always a free model: one billed per song, clip, or image still reports $0 per token, so those are marked metered and left out of a free-only search rather than shown as free.
